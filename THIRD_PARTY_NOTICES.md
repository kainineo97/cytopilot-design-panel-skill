# Third-party notices and provenance

## Bundled material

The current repository snapshot contains no declared third-party script, binary, font, image, template, catalog export, or biological dataset. Both Python files and project documentation use only the Python standard library and project-authored text.

The files in `examples/` are synthetic fixtures created for this repository. Product names, catalog numbers, real clones, patient identifiers, real FCS/WSP files, and manufacturer spectra are intentionally excluded.

## External names and formats

“CytoPilot” identifies this project. Names of fluorophores, markers, instrument concepts, and file formats are used descriptively. Any third-party product names or trademarks remain the property of their respective owners; no endorsement is implied.

Official manufacturer pages may be consulted at runtime when a user explicitly asks for a concrete product. Those pages and their contents are not redistributed here.

## Maintainer verification before first public release

The code and prose were inspected locally, but authorship cannot be established by file inspection alone. Before the first public push, the maintainer should:

1. Confirm that `scripts/design_panel.py`, `SKILL.md`, and `references/` were written by the project or contributed under MIT-compatible terms.
2. Review earlier drafts and commit history for copied snippets or prompts not present in the final directory.
3. Keep real reagent inventories and manufacturer spectral exports outside this repository unless their redistribution terms are documented.
4. Add an attribution entry here for any future adapted code or content, including source URL, copyright holder, license, and modified files.
